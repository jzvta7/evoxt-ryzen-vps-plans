## 这价格表有三条规律，看懂了就不会买错

**核很便宜，内存才是加价项。** 从 VM-2 到 VM-3，多 2 核只多 $3；VM-4 到 VM-6 多 4 核多 $6；VM-8 到 VM-12 多 8 核多 $12.96。折算下来每核大约 $1.5/月。同一核数往上加内存就贵得多，每 GB 内存在 $2.2 到 $2.5/月之间。所以编译、批量处理、跑多个轻进程这类吃并发的活，往上加档很划算；跑数据库、缓存这类吃内存的活，钱基本花在内存上。

## 按用途对号：哪档够用，哪档多数人买多了

**静态站、反代、单只小服务、个人代理** → VM-1。1 核 2GB 跑 Nginx 或 Caddy 加一个轻量应用，内存还剩一半。20GB 存储放系统加日志够，但要留出备份空间。

**多站点托管、CI 构建、中腰部应用** → VM-4。4 核 8GB、60GB 存储，是这张表里配置最均衡的一档，年化 $287.88。

**游戏服务器、实时 API、任务队列** → VM-1.5 或 VM-2，别买多核高配。这类负载吃的是单核主频和响应延迟，8 核帮不上忙。

**编译、视频转码、跑大批量脚本** → VM-6 起。8 核 $29.99 的核价比 VM-4 更便宜，纯算力需求选它比选 VM-8 省钱。

**VM-12 和 VM-16 多数人用不上。** VM-12 是 16 核配 16GB 内存，核内存比 1:1，除了纯并发场景（大量短连接、爬虫池、无状态 API）之外很难吃满，年化 $731.40 对个人站长是纯浪费。VM-16 的 32GB 内存配 100GB 存储，适合真跑内存数据库或虚拟化的团队，个人用户没有对应负载。

**VM-0.5 和 VM-0.75 只适合一种人**：只需要一台常在线的小机器做跳板、探针、定时任务。512MB 内存跑现代面板、数据库或 Java 应用会直接 OOM，5GB 存储装完 Debian 就剩不到 3GB。

**没有按小时计费。** 第三方测评站的规格表明确标注 Evoxt 不支持小时计费，最短一个月的周期。想开一台机器测两小时就跑，成本按整月算。

**不支持 rDNS/PTR 反解。** 想在同一台机器上自建邮件服务器发信，这一条会卡住，投递率很难看。

**支付方式里没有支付宝。** 官网列的是信用卡、借记卡、PayPal、Bitcoin 和 USDT（Tron）。国内用户能用的是 PayPal 或加密货币，没有本地扫码通道。
